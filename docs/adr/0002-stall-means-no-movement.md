# A stall is two rounds with no movement, not a flat disagreement count

The run stops as `stalled` when two Rounds in a row close or escalate no Challenge and contain no Revise or Concede. We rejected "Disagreement did not drop" as the rule: when two Challenges close and two new, deeper ones open in the same Round, the count stays flat, but the deliberation is still doing useful work. The 6-round cap still stops a Critic that keeps raising new issues forever.
